# 视觉与组件设计规范

设计版本：v0.2。已选方向：**晴空蓝白**。产品名称：**搭搭不搭搭**。

## 视觉定位

面向女生的日常衣橱，强调清新、轻盈、方便整理。白色是页面主底，灰蓝用于文字与操作，浅蓝用于局部选中状态。衣物本身的颜色承担视觉主体，留白帮助区分内容层级。

页面标题使用正常字重与清晰行距；图标统一细线SVG；卡片依靠浅底色、间距和少量分隔线区分。产品文案以中文为主，品牌名称在微信标题栏展示，页面标题表达当前任务。

| primary / --primary | `#426E91` | 操作文字、按钮文字、SVG图标 |
| accent / --accent | `#5B8DB7` | 选中细线、焦点、装饰点缀 |
| primary-soft / --soft | `#F0F6FB` | 状态提示、浅蓝选区 |
| action-surface | `#EDF4FA` | 主按钮、选中日期 |
| action-line | `#DCE8F2` | 主按钮边界 |
| line / --line | `#E9EEF3` | 列表、导航、表单分隔 |
| photo / --photo | `#F8F9FB` | 衣物图片底色 |

原型的变量集中在 `prototype/style.css`。微信实现时将相同语义迁移到公共主题WXSS，页面使用语义变量。

按WCAG相对亮度公式计算：正文对白底约8.86:1，辅助文字对白底约4.98:1，主按钮文字对浅蓝底约4.89:1，辅助文字对图片浅底约4.73:1。这些是指定色值组合的检查结果；不代表已完成整应用无障碍验收。用户照片、透明叠层、禁用状态和真机显示仍需逐项检查。

## 字体、尺寸与留白

以390px设计稿为参考，原生实现根据750/390换算rpx，安全区域使用设备实际值。

- 系统中文字体：PingFang SC / Microsoft YaHei / sans-serif。
- 页面标题25px、字重500、行高约1.45；较长标题自然换行。
- 分组标题15px、字重500；正文及表单16px；卡片名称12–13px、字重400；辅助说明11–12px。
- 页面左右22px，分组间距24px，衣物卡片列间距14px、行间距25px。
- 图片区域圆角12px；详情大图16px；操作按钮12px；底部抽屉24px。
- 图标画布24×24，线宽1.5，视觉尺寸18–22px，单独按钮通常为44×44px触控区域。
- 原型覆盖320、375、390、430px宽度；小程序需继续验证键盘、系统字体设置与底部安全区。

## 组件规则

| 组件 | 外观与交互 |
| --- | --- |
| 标题区 | 标题、短说明、右侧细线新增按钮 |
| 搜索与筛选 | 浅灰蓝搜索底、独立筛选图标；弹层保留当前条件 |
| 分类标签 | 横向可滚动；选中为蓝色文字和短下划线，提供aria-pressed |
| 衣物卡片 | 10:11图片区域，contain完整展示；名称、分类/颜色列在下方；收藏显示不同SVG状态 |
| 搭配列表 | 双列缩略画布，图像维持3:4；名称允许换行，场景和单品数量辅助说明 |
| 主按钮 | 浅蓝底、细边框、蓝色文字，高度至少48px；提交期间保持尺寸并禁用 |
| 次按钮 | 白底、浅边框；危险操作使用明确文字和错误色 |
| 表单 | 标签可见，选填信息明确；输入文字16px；底部保存区域保持可见，其他字段可滚动 |
| 日历 | 周一起始；当天细描边、选中日浅蓝底、有记录蓝色圆点；日期行高44px |
| 统计 | 数字采用正常字重，浅底数据块与细条形图；范围和价格覆盖数必须可读 |
| 列表/我的 | 白底分组与细分隔；图标用于定位，数字区域保持轻量 |
| 底部导航 | 四入口、细线SVG和文字；当前页同时改变文字颜色和图标呈现 |
| 提示与弹窗 | 浅底色、文字说明与明确动作；失败/未配置状态有独立文案 |

## 页面细化

- **衣橱**：统一图片底色，名称与分类信息轻量排列；搜索、分类和收藏组合筛选；归档可恢复。
- **衣物录入**：完整照片预览、图像任务入口、分类与资料；底部保存区域与可滚动内容分开呈现，完整字段均可操作。
- **衣物详情**：图片、名称、收藏、标签、统计与资料依次排列；加入搭配是主要动作。
- **搭配编辑**：3:4画布，选中衣物用细虚线框；七个工具在窄屏换为两行，选衣区可横向滚动。
- **搭配详情/穿搭记录**：布局居中，控制画布宽度，为记录按钮和表单保留空间；保存的布局与历史单品集合保持一致。
- **日历**：当日记录在月历下方，以浅底缩略图展示单品；新增记录与补记沿用同一表单。
- **统计/清单/我的**：以数据和操作为主，颜色承担选中、进度与提示含义。
- **智能能力**：天气、推荐、试穿页面沿用相同主题；清楚展示演示标签、服务可用性与图像发送说明。
- **登录**：品牌名称、简短介绍与白衬衫/半裙插画，微信登录作为主要动作。

## 状态与资产

- 正常、加载、空数据、搜索无结果、失败、禁用、选中与删除引用状态纳入评审。
- 文案、下划线、边框、圆点和SVG状态共同表达含义。
- 服装SVG是原创演示插画，不代表真实照片或模型效果；用户图片保留原色并以contain显示。
- Lucide SVG保留许可证；图标明确声明尺寸、viewBox、描边颜色和线宽。
- 收藏图标包含普通与选中资源；缩小工具使用对应减号图标。
- TDesign实际展示的图标需使用支持的资源路径或插槽接入SVG，并在微信开发者工具和真机验证。
