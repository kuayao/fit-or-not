- 模拟任务成功/失败/取消、服务未配置、试穿确认、演示登录；本地演示JSON下载。

## 原型演示边界与正式实现差异

| 内容 | 原型表达 | 正式实现依据 |
| --- | --- | --- |
| 多图批次、拍照、裁剪与草稿恢复 | 单张文件选择；示例主图可直接录入 | F02、P02/P04、A04–A06 |

| 识别与抠图 | 定时器推进状态，原创插画展示候选 | D02模型实测、F04、A11–A16 |
| 画布边界/手势/封面 | HTML指针操作；局部越界、旋转边界尚需原生算法落实 | P06、数据设计、A18/A19 |
| 搭配元数据与导出 | 核心布局可保存；场景/季节/背景编辑和PNG导出需正式实现 | F05、P06/P07 |
| 直接选衣与上身照 | 原型穿搭记录使用已保存搭配或已有快照 | F06、P09、穿搭接口 |
| 清单完整编辑/删除、分类迁移/排序 | 主流程和提示，部分操作为说明浮层 | F08/F09、接口清单 |

## 复现方式

先在项目根目录启动本地静态服务：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/design
```

浏览器检查脚本使用已有Playwright和Chrome；没有向项目安装依赖：

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/node_modules/playwright \
CHROME_EXECUTABLE='/absolute/path/to/Chrome' \
node docs/design/verification/check-prototype.cjs
```

脚本只访问本地原型、操作演示数据、生成截图和JSON验证报告。路径由实际环境提供；默认 `PROTOTYPE_URL=http://127.0.0.1:8765/prototype/`。

文档本地链接和SVG结构检查：

```sh
python3 docs/design/verification/check-documents.py
```
