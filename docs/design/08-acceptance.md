## 镜像升级专项验收

在独立测试库和实际发布镜像上执行，以下项目均待实现/待验证：

- 空库只通过运行镜像完成初始化；从上一发布版本带数据升级，新增结构生效且原业务数据保留。
- 同版本重复启动不重复执行 SQL；两个容器同时启动时迁移互斥，历史记录一致。
- 历史脚本被修改、迁移 SQL 出错、数据库连接或锁等待超时，均非零退出且 API 不就绪，worker 不领取任务。
- 事务内迁移失败不留下当前迁移的部分写入；恢复后正确继续未完成迁移，已提交版本不重复执行。
- 数据库领先于镜像时阻止不受支持的降级；升级前备份可以恢复至独立环境。
- 按发布说明仅导入镜像并运行更新命令完成 API/worker 更新，旧进程在迁移前停止，持久化卷保留，全程无需手动 SQL。
