## 已确认的产品边界

- 只做微信小程序，主要供本人和朋友共 2–3 人使用，各自管理自己的衣橱。
- 使用自有服务器，PG 同机，数据库镜像基线 `postgres:18.6-alpine`。
- 用户提供的截图显示：4 核，内存 893.17 MB / 3.32 GB，根目录 10.03 GB / 39.26 GB。这是单时点观察，不能作为推理峰值测试结果。
- 自动抠图和衣物识别由服务端 worker 调用 New API；抠图模型为 `gpt-image-2.6-flare`，识别模型独立配置；衣物数据与结果图片保存到个人云端衣橱。
- 主要面向女生，视觉已选「晴空蓝白」：白色主底、灰蓝点缀、细线图标和轻盈留白。
- 美观、轻量、录入方便；图标使用 SVG；工程遵循根目录 `AGENTS.md`。

## 设计采用的明确假设

以下是本设计的完整默认方案，用户可以逐条调整：

- 默认四个导航入口：衣橱、搭配、日历、我的。
- 搭配采用自动排版，支持拖动、缩放、旋转和调整层级；记录穿着后才计入穿着次数。
- 包含旅行清单、统计、导出、归档、标签管理和账号注销。
- 包含天气建议、AI 搭配和虚拟试穿的产品与接口设计。正式交付这些功能前，必须落实服务商、费用上限及实际集成；配置缺失时明确显示不可用状态。
- 朋友间通过用户主动导出的搭配图片交流；每人的衣橱和上身照片保持私有。
- 品牌、价格、尺码、面料由用户填写；AI 提供名称、分类、色系及其他可见资料建议，由用户采用后保存。

## 交付物性质

当前交付物是产品/技术设计、HTML 交互原型、SVG 设计图与浏览器导出的 PNG。原型里的图像处理、识别、天气、AI 结果均为明确标识的演示，不代表模型或远端 API 已实现。

HTML 原型用于审阅信息结构与交互；微信原生实现以对应页面规格为准。原型本地 SVG 服装插画是本项目绘制的示例资产；图标源于 Lucide，许可证随资产保留。

## 本地查看

在项目根目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/design
```

然后访问 `http://127.0.0.1:8765/prototype/index.html`。也可以直接打开 HTML；HTTP 方式更适合设计图总览与浏览器检查。原型不需要安装应用依赖或连接数据库。
